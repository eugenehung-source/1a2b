# 1A2B 每日猜數字

[![test](https://github.com/eugenehung-source/1a2b/actions/workflows/test.yml/badge.svg)](https://github.com/eugenehung-source/1a2b/actions/workflows/test.yml)

一個手機、電腦都能玩的 1A2B 猜數字網頁遊戲：每天一題、可以分享戰績，也可以隨時練習。

**👉 立即遊玩：<https://eugenehung-source.github.io/1a2b/>**

## 玩法

猜出一組數字（可以 0 開頭）。每猜一次會得到提示：

- **A**：數字對、位置也對
- **B**：數字對，但位置不對

例：答案是 `1234`，猜 `1325` → `1A2B`。

猜的時候可以輸入重複數字來試探，每個數字只算答案裡有的次數：答案是 `1234`，猜 `1111` → `1A0B`。

答案有兩種版本：**不重複**（經典規則，每日挑戰與練習預設）和**可重複**（練習中打開「可重複」，例如答案 `1123`、猜 `1111` → `2A0B`）。

## 功能

- **每日挑戰**：每天台灣時間 00:00 換題，所有人同一題（4 位數、10 次），猜完可複製 emoji 戰績分享，不會洩漏答案
- **自由練習**：簡單（3 位／8 次）、普通（4 位／10 次）、困難（5 位／12 次），可切換答案「不重複／可重複」
- **筆記標記**：把數字標成「一定有／一定沒有」幫助推理（✏️ 標記模式、長按、右鍵或 `Shift` + 數字）
- **統計**：遊玩次數、勝率、連勝、最佳紀錄、最快時間、猜測次數分布（存在瀏覽器裡）
- **計時**：從第一個數字開始計時，離開畫面會暫停；每日分享會附上時間
- **賽後分析**：每局結束後，每一步顯示「還剩幾種可能」
- **補玩過去題目**：漏玩的每日題可以補玩（不計入統計和連勝）
- 手機與電腦同等支援：螢幕鍵盤、實體鍵盤（`0`–`9`、`Backspace`、`Enter`）、深色模式

## 技術

純 HTML / CSS / JavaScript，不用框架。**網站本身是根目錄的單一 [`index.html`](index.html)**，CSS 與 JavaScript 都內嵌在裡面，直接由 GitHub Pages 提供。

為了方便測試，原始碼分檔放在 `src/`：遊戲規則是可測試的純函式模組（`game.js`、`daily.js`、`stats.js`、`share.js`），以 [Vitest](https://vitest.dev/) 測試；`ui.js` 只負責畫面與操作。`scripts/build.mjs` 把它們合併成單一 `index.html`。

```bash
npm install
npm test          # 執行測試（含檢查 index.html 是否已重新合併）
npm run build     # 修改 src/ 之後，重新產生 index.html
```

本機預覽：

```bash
npx serve .
```

完整的規格請見 **[規格書](規格書.md)**。

## 開發過程

這是「用 Vibe Coding 做出一個互動網頁」的作業，重點在於把想法說清楚、和 AI 討論出規格，再實作：

1. **發想（brainstorming）**：和 AI 一問一答，從「做個小遊戲」收斂到「1A2B 猜數字＋每日挑戰＋筆記＋統計」，比較三種技術做法後選擇純 JS + Vitest。
2. **拷問（grilling）**：AI 逐輪追問被默默假設的細節，例如跨午夜怎麼換題、放棄的局算不算輸、重複數字何時擋、每日答案能被看穿要不要防，共 24 個決策。
3. **規格**：定案寫成 [規格書](規格書.md)（開發用的詳細版：[設計規格](docs/superpowers/specs/2026-10-14-1a2b-game-design.md)）。
4. **實作計畫**：拆成 9 個任務的 [實作計畫](docs/superpowers/plans/2026-10-16-1a2b-game.md)。
5. **垂直 TDD 實作**：每個規則都是「先寫一個會失敗的測試 → 寫剛好讓它通過的程式」一個切片接一個切片完成；畫面部分在手機與桌機尺寸實際操作驗收。
6. **部署**：GitHub Actions 每次 push 自動跑測試，GitHub Pages 發布網頁。
