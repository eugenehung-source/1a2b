# 1A2B 每日猜數字 — 設計規格

日期：2026-10-14（grilling 定案 2026-10-16）
狀態：brainstorming＋grilling 已確認，達成共識

## 目的

課堂作業「用 Vibe Coding 做出一個互動網頁」：把想法說清楚 → 和 AI 討論規格 → Vibe Coding 實作 → 公開在 GitHub Pages。

作品是一個手機與桌機都能完整遊玩的 1A2B 猜數字遊戲，特色為每日挑戰＋分享戰績、難度選擇、筆記盤、統計紀錄。

## 1. 遊戲規則

- 答案由 0–9 組成，**數字可以重複**（每一位獨立隨機），允許 0 開頭（例如 `0371`、`1123`）。（2026-10-17 變更：原本規定不重複，使用者要求改為可重複。）
- 每次猜測回饋 `xAyB`：A＝數字與位置都對；B＝數字對但位置錯。重複數字採 Mastermind 算法：每個數字計入 A+B 的次數，最多為它在答案與猜測中出現次數的較小值（答案 `1123`、猜 `1111` → `2A0B`）。
- 猜測也可以有重複數字；輸入已滿時再按數字一律忽略。
- 不合法的猜測不扣次數，直接顯示錯誤訊息：
  - 長度不對
  - 與先前猜過的相同
- 全部都是 A 即獲勝；用完次數則失敗，並公布答案。

## 2. 模式

| | 每日挑戰 | 自由練習 |
|---|---|---|
| 題目 | 依日期決定，所有人同一題；以台灣時間（UTC+8）00:00 換題 | 隨機 |
| 難度 | 固定 4 位數、10 次 | 自選：簡單 3 位／8 次、普通 4 位／10 次、困難 5 位／12 次 |
| 遊玩 | 一天一次；重新整理後保留當天進度（猜測與筆記標記） | 可無限重開 |
| 分享 | 結束後可複製戰績 | 無 |

- 開啟頁面預設進入每日挑戰。
- 上次選的練習難度存在 localStorage，下次沿用。

### 題號與答案

- 題號 `#N`：上線日（常數 `DAILY_EPOCH`，台灣時間日期，部署時填入實際上線日）為 #1，之後每天加 1。
- 答案由題號經有種子的亂數產生；同一題號永遠得到同一答案。
- 接受「讀原始碼即可算出答案」——無後端，作業性質不值得防。

### 換日行為

- 每日局未完成時：頁面開著就繼續玩原題；重新載入時若已換日，載入新題，前一天未完成的局不計入統計（連勝因當天沒贏而自然中斷）。
- 每日局已完成時：顯示「距離下一題」倒數（台灣時間 00:00）；歸零時自動載入新題。若玩家正在練習模式，只更新每日狀態，不打斷練習。

### 練習局的保存與放棄

- 練習進行中局面只存在記憶體：同一次瀏覽中切換到每日再切回可接續；重新整理即開新局。
- 進行中按「新的一局」或切換難度時跳出確認；被放棄的局不計入統計。

### 分享格式

不洩漏答案數字，只顯示每次猜測的 A/B 數量，最後一行附網址：

```
1A2B 每日 #12  6/10
🟢🟡🟡⚪
🟢🟢⚪⚪
...
🟢🟢🟢🟢
https://<帳號>.github.io/1a2b/
```

- 每列依序放 A 個 🟢、B 個 🟡，其餘補 ⚪，總數等於位數。
- 失敗時標題的次數顯示為 `X/10`。

## 3. 筆記盤（數字鍵盤兼標記）

- 畫面下方 0–9 大按鈕；一般點擊＝輸入該數字。
- 標記狀態循環：未知 → 一定有（綠色框線）→ 一定沒有（灰色＋刪除線）→ 未知。
- 切換標記的方式：
  - 「✏️ 標記模式」切換鈕（手機、桌機皆有）：開啟時點數字改為切換標記。
  - 快捷：手機長按、桌機右鍵、鍵盤 `Shift + 數字`。
- 標記僅供參考，不阻止輸入、不自動推理。
- 每局獨立；新局清空。每日挑戰的標記隨當天進度保存。
- 另有「刪除」「送出」按鈕。

## 4. 桌機支援（與手機同等級）

- 同一套直式版面，桌機上置中、最大寬度約 480px；視窗高時歷史區顯示更多列。
- 實體鍵盤可完成整局：數字輸入、`Backspace` 刪除、`Enter` 送出、`Shift + 數字` 標記。
- hover 樣式只在 `(hover: hover)` 的裝置套用。

## 5. 統計

存在瀏覽器 localStorage，不跨裝置同步。

- 每日挑戰：遊玩次數、勝率、目前連勝、最長連勝、猜測次數分布（1…10＋失敗）。
  - 連勝＝連續每天都有贏；中間漏一天或輸一次即歸零。
- 自由練習：依難度分開，各自記錄局數、勝率、最佳（最少次數）、猜測次數分布（1…上限＋失敗）。
- 統計視窗上方分頁 `[每日｜簡單｜普通｜困難]`，預設開目前模式（與難度）那頁；每頁顯示數字卡片＋分布長條圖，本局那一條標亮。
- 右上角 📊 隨時可開。

## 6. 畫面

### 主畫面（手機直式）

```
┌─────────────────────┐
│ 1A2B  [每日|練習] ❓📊 │  頂部：模式切換、說明、統計
│ 難度：普通 (練習才有)  │
├─────────────────────┤
│ 1. 0 3 7 1   1A2B   │
│ 2. 5 3 9 0   0A3B   │  猜測歷史（可捲動）
├─────────────────────┤
│   [ _ _ _ _ ]  3/10  │  目前輸入、已用次數
├─────────────────────┤
│ 1 2 3 4 5           │
│ 6 7 8 9 0     ✏️     │  數字鍵（顯示標記狀態）
│ [刪除]      [送出]    │
└─────────────────────┘
```

### 結束畫面

輸入區換成結果橫幅：勝「🎉 第 N 次猜中！」、敗「答案是 0371」。

- 每日：橫幅含 [分享] [統計] 與倒數；並自動跳出統計視窗（視窗內也有分享鈕）。
- 練習：橫幅含 [再來一局]；不自動跳統計。

### 說明

❓ 按鈕顯示規則與範例（答案 `1234`、猜 `1325` → `1A2B`）；第一次造訪自動跳出一次（localStorage 記住已看過）。

### 視覺

- 深淺色跟隨系統（`prefers-color-scheme`），不做切換鈕。
- 系統字型，不載入外部字體。
- 輕量動畫：新一列淡入、錯誤抖動、獲勝小慶祝；無音效。
- 介面只有繁體中文。

### 無障礙

- 每列結果一定以文字 `xAyB` 呈現，不只靠顏色。
- 筆記標記以框線／刪除線區分，不只靠顏色。
- 結果與錯誤訊息透過 `aria-live` 播報。
- 按鈕皆有可讀標籤（例如「標記模式」「統計」）。

## 7. 技術與架構

純 HTML/CSS/JS，部署在 GitHub Pages。支援近兩年主流瀏覽器（Chrome、Edge、Safari、Firefox，含 iOS Safari、Android Chrome）。不做 PWA／離線。

2026-10-18 變更（作業要求「整理成單一 index.html」）：原始碼仍分檔放在 `src/`，以零依賴的 `scripts/build.mjs`（`npm run build`）把 CSS 與所有模組內嵌成根目錄的單一 `index.html`；各模組合併到同一個 script 範圍，頂層名稱不可重複。測試 seam `buildSingleFile()`（已與使用者確認）：不引用外部 CSS/JS、無殘留 import/export 且可被解析、內容完整、根目錄 `index.html` 與產出一致（CI 據此檢查是否忘了重新合併）。

```
1a2b/
├─ index.html      產出的單一檔案（GitHub Pages 提供這個）
├─ 規格書.md        給人讀的規格書（作業交付）
├─ scripts/build.mjs  合併 src/ → index.html
├─ src/

│  ├─ style.css
```

### TDD seam（已與使用者確認）

| Seam | 要測的行為 |
|---|---|
| `game.js`：`validateGuess(guess, length, history)`、`score(secret, guess)`、`randomSecret(length, rng)` | 計分正確（含全 A、0A0B、0 開頭、重複數字）；兩種錯誤原因 `'length' \| 'repeated'`；產生的答案長度正確、只含數字、可重複 |
| `daily.js`：`dailyNumber(date)`、`dailySecret(n)` | 台灣時間 23:59／00:00 換日邊界；上線日＝#1；同題號同答案；答案合法 |
| `stats.js`：`recordResult(stats, result)` | 勝負與分布累計；連勝延續、輸了歸零、漏一天歸零；練習最佳紀錄；不改動輸入物件 |
| `share.js`：`shareText(dayNumber, results, maxGuesses, url)` | emoji 排列（A🟢、B🟡、其餘⚪）；失敗顯示 `X/10`；最後一行附網址 |

- 不 mock 任何內部模組；唯一注入的是 `randomSecret` 的 `rng`（外部不確定來源）。
- `storage.js`、`ui.js` 不寫單元測試，以瀏覽器實際操作驗收（手機 375px 寬與桌機尺寸各一次）。

### 資料流

輸入 → `ui.js` 呼叫 `validateGuess` → 合法則 `score` → 更新畫面狀態 → 遊戲結束時 `recordResult` → `storage.js` 存檔。

### 錯誤處理

- localStorage 不可用（無痕、被封鎖）或資料損毀：遊戲照常進行但不保存；損毀資料重設，頁面不崩潰。
- 剪貼簿 API 失敗：改顯示文字框讓使用者手動複製。

## 8. 測試策略

- 垂直 TDD（tracer bullet）：一個測試 → 看到失敗 → 最少實作 → 下一個測試；重構不在迴圈內。
- 只透過上述 seam 測試行為。
- GitHub Actions 在每次 push 執行 `npm test`。

## 9. 環境與部署

- 本機以 winget 安裝 Node.js LTS 與 GitHub CLI（`gh`）；`gh auth login` 由使用者在瀏覽器完成。
- 公開 repo `1a2b`；GitHub Pages 從預設分支根目錄發布。頁面標題「1A2B 每日猜數字」。
- `node_modules/` 列入 `.gitignore`。
- 部署當天將 `DAILY_EPOCH` 設為上線日。
