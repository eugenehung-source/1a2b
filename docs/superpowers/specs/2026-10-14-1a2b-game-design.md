# 1A2B 猜數字遊戲 — 設計規格

日期：2026-10-14
狀態：brainstorming 已確認，待 grilling

## 目的

課堂作業「用 Vibe Coding 做出一個互動網頁」：把想法說清楚 → 和 AI 討論規格 → Vibe Coding 實作 → 公開在 GitHub Pages。

作品是一個手機與桌機都能完整遊玩的 1A2B 猜數字遊戲，特色為每日挑戰＋分享戰績、難度選擇、筆記盤、統計紀錄。

## 1. 遊戲規則

- 答案由 0–9 組成、數字不重複，允許 0 開頭（例如 `0371`）。
- 每次猜測回饋 `xAyB`：A＝數字與位置都對；B＝數字對但位置錯。
- 不合法的猜測不扣次數，直接顯示錯誤訊息：
  - 長度不對
  - 有重複數字
  - 與先前猜過的相同
- 全部都是 A 即獲勝；用完次數則失敗，並公布答案。

## 2. 模式

| | 每日挑戰 | 自由練習 |
|---|---|---|
| 題目 | 依日期決定，所有人同一題；以台灣時間（UTC+8）00:00 換題 | 隨機 |
| 難度 | 固定 4 位數、10 次 | 自選：簡單 3 位／8 次、普通 4 位／10 次、困難 5 位／12 次 |
| 遊玩 | 一天一次；重新整理後保留當天進度（猜測與筆記標記） | 可無限重開 |
| 分享 | 結束後可複製戰績 | 無 |

### 題號

- 題號 `#N`：上線日（常數 `DAILY_EPOCH`，台灣時間日期）為 #1，之後每天加 1。
- 答案由題號經有種子的亂數產生；同一題號永遠得到同一答案。

### 分享格式

不洩漏答案數字，只顯示每次猜測的 A/B 數量：

```
1A2B 每日 #12  6/10
🟢🟡🟡⚪
🟢🟢⚪⚪
...
🟢🟢🟢🟢
```

- 每列依序放 A 個 🟢、B 個 🟡，其餘補 ⚪，總數等於位數。
- 失敗時標題的次數顯示為 `X/10`。

## 3. 筆記盤（數字鍵盤兼標記）

- 畫面下方 0–9 大按鈕；一般點擊＝輸入該數字。
- 標記狀態循環：未知 → 一定有（綠框）→ 一定沒有（灰色劃掉）→ 未知。
- 切換標記的方式：
  - 「✏️ 標記模式」切換鈕（手機、桌機皆有）：開啟時點數字改為切換標記。
  - 快捷：手機長按、桌機右鍵、鍵盤 `Shift + 數字`。
- 標記僅供參考，不阻止輸入、不自動推理。
- 每局獨立；新局清空。每日挑戰的標記隨當天進度保存。
- 另有「刪除」「送出」按鈕。

## 4. 桌機支援（與手機同等級）

- 同一套直式版面，桌機上置中、最大寬度約 480px；視窗高時歷史區顯示更多列。
- 實體鍵盤可完成整局：數字輸入、`Backspace` 刪除、`Enter` 送出、`Shift + 數字` 標記。
- hover 樣式只在 `(hover: hover)` 的裝置套用。

## 5. 統計

存在瀏覽器 localStorage，不跨裝置同步。

- 每日挑戰：遊玩次數、勝率、目前連勝、最長連勝、猜測次數分布（1…10＋失敗）。
  - 連勝＝連續每天都有贏；中間漏一天或輸一次即歸零。
- 自由練習：依難度分開，各自記錄局數、勝率、最佳（最少次數）、猜測次數分布。
- 每日挑戰結束時自動跳出統計視窗；右上角 📊 隨時可開。

## 6. 畫面（手機直式）

```
┌─────────────────────┐
│ 1A2B   [每日|練習] 📊 │  頂部：模式切換、統計
│ 難度：普通 (練習才有)  │
├─────────────────────┤
│ 1. 0 3 7 1   1A2B   │
│ 2. 5 3 9 0   0A3B   │  猜測歷史（可捲動）

├─────────────────────┤
```

## 7. 技術與架構

純 HTML/CSS/JS（ES modules），無建置步驟，直接部署 GitHub Pages。Node 只用於跑 Vitest。

```
1a2b/
├─ index.html
├─ style.css
├─ src/
│  ├─ game.js      核心規則（純函式）
│  ├─ daily.js     每日題號與答案（純函式）
│  ├─ stats.js     統計計算（純函式）
│  ├─ share.js     分享文字（純函式）
│  ├─ storage.js   localStorage 讀寫（薄包裝、容錯）
│  └─ ui.js        DOM、事件、鍵盤；串接上述模組
├─ tests/          Vitest，只測 game / daily / stats / share
└─ package.json    唯一 devDependency：vitest
```

### 公開介面（TDD seam 候選，實作前再與使用者確認）

- `game.js`
  - `validateGuess(guess, length, history)` → `{ ok: true }` 或 `{ ok: false, reason: 'length' | 'duplicate' | 'repeated' }`
  - `score(secret, guess)` → `{ a, b }`
  - `randomSecret(length, rng)` → 不重複數字字串；`rng` 可注入
- `daily.js`
  - `dailyNumber(date)` → 題號（以台灣時間計算）
  - `dailySecret(n)` → 題號 n 的 4 位數答案（有種子亂數，決定性）
- `stats.js`
  - `recordResult(stats, { won, guesses, dayNumber? })` → 新統計物件（不改動輸入）；含連勝邏輯
- `share.js`
  - `shareText(dayNumber, results, maxGuesses)` → 分享文字

### 資料流

輸入 → `ui.js` 呼叫 `validateGuess` → 合法則 `score` → 更新畫面狀態 → 遊戲結束時 `recordResult` → `storage.js` 存檔。

### 錯誤處理

- localStorage 不可用（無痕、被封鎖）或資料損毀：遊戲照常進行但不保存；損毀資料重設，頁面不崩潰。
- 剪貼簿 API 失敗：改顯示文字框讓使用者手動複製。

## 8. 測試策略

- 只透過上述公開函式測試；不 mock 內部協作者。
